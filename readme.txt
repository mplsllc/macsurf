No cache-clearing needed.There were two real causes.  MacSurf checked whether apointer was "valid" against fixed address ceilings thatwere simply wrong on higher-RAM Macs, where the program'smemory maps higher up - so it rejected perfectly goodpointers, string matching broke, and no page everfetched.  It now reads the real memory bounds from thesystem at launch.  Separately, the "dead host" list thatkeeps an unreachable server from stalling a page wasbeing saved to disk with no expiry, so one bad networkmoment could condemn your home page forever; that list isnow session-only, and 2.0 deletes any poisoned list anolder version left behind.(About the Virtual Memory workaround: toggling VM neveractually did anything - we measured it, on and off lookedidentical.  If it seemed to help, that was the restart.)MORE OF THE WEB, OVER HTTPS.MacSurf's TLS stack was strict about certificate order,and many servers - macintoshgarden.org among them - sendtheir certificates out of order.  MacSurf now sorts themout, so a whole family of sites that used to fall back toplain http open securely on the Mac.FASTER.Off-screen images now wait until you scroll to them, forevery image on the page.  A busy forum thread with a bigattachment went from 20 seconds-to-two-minutes down to afew seconds.  And typing in text fields is snappy again -each letter paints the instant you press it.NICER TO USE.The address bar now finishes URLs from your history asyou type, with a dropdown of the other matches.  There isa real History manager (History > Show All History,Cmd-H) and a folder-based Bookmark manager (Bookmarks >Manage Bookmarks, Cmd-B) with drag-and-drop.  Plus arefreshed toolbar, a new About box, and a Clear Cachemenu item.Get Info now shows the version, and the About box,User-Agent, and navigator.userAgent all reportMacSurf/2.0.If a blank page still happens on 2.0, please tell us onGitHub issue #207 and attach MacSurf Debug.log.  Thatwould mean a cause we haven't seen yet.   -------------------------------------------------     TO RUN   -------------------------------------------------   Expand this archive with StuffIt Expander and double-   click MacSurf.  No installer, no configuration.     Requirements:  Power Macintosh (G3 or G4)                    Mac OS 9.1 - 9.2.2, CarbonLib 1.5+                    ~64 MB RAM (more helps on heavy pages)   -------------------------------------------------     A FEW THINGS TO KNOW   -------------------------------------------------   *  Very heavy sites (such as GitHub) don't render yet.      To download new MacSurf releases from a Mac OS      machine, use the plain non-SSL (http) version of      macsurf.org - no other computer needed.   *  Tab reaches form fields, but not links or buttons      yet.   *  Tabs (several pages in one window) are not enabled      yet.   -------------------------------------------------     THANK YOU, 68kmla.org   -------------------------------------------------   68kmla.org - the 68k / PowerPC Mac community - has   been so kind and welcoming, tested MacSurf every   single day, and shaped this whole stretch of work.
