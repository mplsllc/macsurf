No cache-clearing needed:1.68.3 repairs an affected machine automatically thefirst time you launch it.The reason:  MacSurf keeps a list of "dead hosts" so anunreachable server can't stall a page with dozens ofdoomed requests.  That list was being saved to disk,inside the Cache folder, and reloaded on every launch -with no expiry.So one bad moment on your network - a single timed-outconnection, one dropped handshake - was enough to writea server into that file permanently.  Every launch afterthat refused to even try contacting it.  If the servercondemned happened to be your home page, MacSurf openedto a blank window, forever.Deleting the cache erased the file, which is why itseemed to help.  But the next network hiccup wrote itagain - which is why the fix never stuck.Now the dead-host list lives only for the currentsession.  A server can no longer be condemned by one badmoment, the list never survives a relaunch, and typing aURL or clicking a bookmark always means "try this now".About the Virtual Memory workaround:  toggling VirtualMemory never actually did anything.  We measured it onreal hardware - with VM on and with VM off, MacSurf'smemory looked identical and unfragmented both ways.  Ifit seemed to help, that was the restart.  The $0000memory bug fixed in 1.68.1 and 1.68.2 was real and staysfixed; it just wasn't what made the page go blank.ALSO NEW:History manager - a real, persistent, clearable history,grouped by day and scrollable  (History > Show AllHistory, Cmd-H).Bookmark manager - folders, rename, delete, drag-and-dropreordering, and a folder picker for moves  (Bookmarks >Manage Bookmarks, Cmd-B).  The Bookmarks menu now nestsfolders as submenus.Clear Cache menu item  (History menu).Image-heavy pages load faster.  Avatar-rich forum threadswere re-laying-out the whole page for every image thatfinished loading.  Reflows on a typical forum page fellfrom about 15 to 2-4.JavaScript is more responsive, with less event-loopoverhead while scripts run.Better bug reports - MacSurf Debug.log now carries aper-session header with the version, build stamp andlaunch time, and flushes its first lines immediately so afailure during startup still leaves evidence behind.Version reporting - About box, User-Agent, andnavigator.userAgent all report MacSurf/1.68.3.If a blank page still happens on 1.68.3, please tell uson GitHub issue #207 and attach MacSurf Debug.log.  Thatwould mean a second cause we haven't seen yet.   -------------------------------------------------     TO RUN   -------------------------------------------------   Expand this archive with StuffIt Expander and double-   click MacSurf.
