Justdrop it in over 2.0 - no new setup, nothing to configure.HACKADAY RENDERS.Point MacSurf at hackaday.com and the front page comes up -at real desktop width, correct fonts, the article cards laidout, images in place.  A big, modern, JavaScript-heavy newssite, rendering on a G3.  That is what this release is namedfor, and a lot of work sits under it.(Honest about it: this is pages RENDERING - coming upcorrect and readable.  Deep interactivity on the heaviestsites is still being built.  But blank, squished, andunstyled are largely behind us.)TEXT IS THE RIGHT SIZE AGAIN.The quiet fix that mattered most.  Every font size in thebrowser was drawing about 25% too small, and CSS em / remunits and @media width queries were all measuring againstthe wrong number - which is why so many sites came upcramped into a narrow column instead of the full desktoplayout.  Fixed at the root: MacSurf now measures type inreal device pixels, like every other browser.A LARGE JUMP IN CSS.MacSurf now handles a whole cluster of modern layout andtext features it didn't before - several that no otherclassic-Mac browser has done, and a few the upstreamNetSurf engine doesn't ship either: *  Justified text that spreads words to both margins. *  Soft hyphens - long words break with a "-" at line end. *  tab-size, so code and pre-formatted text line up. *  Flexbox cross-axis alignment, and the box-alignment    shorthands (place-items / place-content / place-self). *  CSS Logical Properties (margin-inline, padding-block,    inset-* and friends). *  Grid columns that auto-size to their content. *  caret-color, text-decoration color/style/thickness,    text-align-last, and a real "background: none" reset.PAGES READ THE WAY THEY SHOULD.Plain-text and status pages show in the window instead ofdownloading themselves.  Squished-into-a-strip images comein at the right shape.  More JPEGs decode instead of drawingblack boxes, and an over-large photo shrinks to fit insteadof vanishing.  See-through (rgba) backgrounds blend againstwhat's behind them instead of assuming white.  White text ona dark background stays white.HACKER NEWS WORKS.You can log in, and the front page renders close to adesktop browser - orange logo, vote arrows, no phantomboxes around every story.FASTER, AND CLEANER.Typing in a text field is snappy again - each keystrokerepaints only what changed, not the whole page (that helpsthe caret, hover, and small scrolls too).  And known trackerand ad-network hosts are now refused before they load, sothe Mac isn't grinding through junk before the real contentarrives.Get Info, the About box, User-Agent, andnavigator.userAgent all report MacSurf/2.0.5.   -------------------------------------------------     TO RUN   -------------------------------------------------   Expand this archive with StuffIt Expander and double-   click MacSurf.  No installer, no configuration.     Requirements:  Power Macintosh (G3 or G4)                    Mac OS 9.1 - 9.2.2, CarbonLib 1.5+                    128 MB RAM minimum; 256 MB recommended                    (384 MB for the heaviest JavaScript sites)   -------------------------------------------------     A FEW THINGS TO KNOW   -------------------------------------------------   *  Very heavy sites (such as GitHub) don't render yet.      To download new MacSurf releases from a Mac OS      machine, use the plain non-SSL (http) version of      macsurf.org - no other computer needed.   *  Tab reaches form fields, but not links or buttons      yet.   *  Tabs (several pages in one window) are not enabled      yet.   -------------------------------------------------     THANK YOU, 68kmla.org   -------------------------------------------------   68kmla.org - the 68k / PowerPC Mac community - has   been so kind and welcoming, tested MacSurf every   single day, and shaped this whole stretch of work.
