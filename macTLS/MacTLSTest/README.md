# MacTLSTest

Standalone Carbon CFM app for Stage A validation of macTLS on real
OS 9 hardware. NOT a browser. NOT a proxy yet. ONE job: prove that the
vendored BearSSL subset compiles under CW8, statically initialises in
an OS 9 PowerPC process, and reaches the "ClientHello queued" engine
state without crashing.

When this app reports `smoke OK` on G3 / OS 9.1 hardware (and the Stage
A.5 mul64 probe at [`../tools/probes/ppc_mul64/`](../tools/probes/ppc_mul64/)
also passes), this same project evolves into **MacTLS Proxy** — the
local HTTP-proxy app that gives any OS 9 browser HTTPS support.

## Contents

| File                       | What it is                                                                |
| -------------------------- | ------------------------------------------------------------------------- |
| `main.c`                   | Carbon `main()`: toolbox init, smoke test call, result-display window     |
| `mactlstest_prefix.h`      | CW8 project prefix; pulls in `ostls_cw8_prefix.h` for BearSSL settings    |
| `MacTLSTest.rsrc`          | Binary resource fork with the required `'carb'(0)` Carbon-fragment marker |

The `.rsrc` is byte-identical to `browser/netsurf/frontends/macos9/MacSurf.rsrc`
and is generated by `../tools/make_carb_rsrc.py`. Do not edit it by hand;
regenerate if needed:

```sh
python3 ../tools/make_carb_rsrc.py MacTLSTest.rsrc
```

## What the app does

1. Standard Carbon init (`InitCursor`, `FlushEvents`, Gestalt-gated
   `RegisterAppearanceClient`). No `InitGraf` / `InitFonts` / etc. —
   CarbonLib handles those.
2. Calls `OSTLS_SmokeTest()` exactly once.
3. Opens a small modeless window and draws the result code.
4. Waits for a mouse click or key press, then quits.

No Open Transport. No network. No filesystem writes. No menus. The
smallest possible CW8 program that can host BearSSL.

## Setting up `MacTLSTest.mcp` on the Mac

This `.mcp` does **not** exist in the source tree — you create it in
CW8 on the Mac. One-time setup:

### 1. New project

CW8 → File → New Project... → **Mac OS C Stationery → MacOS Carbon →
MacOS Carbon C** (or "MacOS Carbon C++" — same thing). Save as
`MacTLSTest.mcp` somewhere inside `macsurf-source Folder:macTLS:MacTLSTest:`.

### 2. Project prefix

CW8 → Edit → MacTLSTest Settings → C/C++ Language →
**Prefix File:** `mactlstest_prefix.h`

### 3. Access paths

Edit → MacTLSTest Settings → Target → Access Paths → User Paths,
add (non-recursive, like MacSurf):

```
{Project}::patrick:macsurf-source Folder:macTLS:bearssl:inc:
{Project}::patrick:macsurf-source Folder:macTLS:bearssl:src:
{Project}::patrick:macsurf-source Folder:macTLS:os9:
{Project}::patrick:macsurf-source Folder:macTLS:MacTLSTest:
```

System paths (same as MacSurf):

```
{Compiler}:MacOS Support:Universal:Interfaces:CIncludes:
{Compiler}:MacOS Support:MacHeaders:
{Compiler}:MSL:MSL_C:MSL_Common:Include:
{Compiler}:MSL:MSL_Extras:MSL_Common:Include:
{Compiler}:MSL:MSL_C:MSL_MacOS:Include:
```

### 4. Source files

Add all 255 `.c` files from [`../tools/bearssl_cw8_files.txt`](../tools/bearssl_cw8_files.txt)
plus these three:

```
macTLS/os9/ostls_entropy.c
macTLS/os9/ostls_smoketest.c
macTLS/MacTLSTest/main.c
```

Plus the resource file:

```
macTLS/MacTLSTest/MacTLSTest.rsrc
```

(CW8 links `.rsrc` files into the binary's resource fork at build time.
No Rez step required.)

### 5. Project settings

| Setting                                | Value                |
| -------------------------------------- | -------------------- |
| Linker → MacOS PPC Linker → File Type | `APPL`               |
| Linker → MacOS PPC Linker → Creator   | `MSTL` (any 4-char OSType you like) |
| Linker → MacOS PPC Linker → Application | check               |
| PPC PEF → Application Heap Size       | 4 MB or higher       |
| PPC PEF → Minimum Heap Size           | 2 MB                 |

(The smoke test allocates ~70 KB statically. 4 MB is overkill but
gives breathing room for any per-suite registration that pulls in
larger transient buffers. We are NOT in MacSurf's 16 MB territory yet
because there are no live HTTP fetches.)

### 6. Build and run

Remove Object Code → Make. First-time compilation of 255 .c files
will take a while. After it finishes, double-click the built `MacTLSTest`
app on the Mac.

## What success looks like

Window title: **MacTLSTest — smoke OK**

Window body:
```
macTLS Stage A smoke: OK
BearSSL initialised; engine reports SENDREC.

Click mouse or press any key to quit.
```

If you see this on the development G3 (OS 9.1) and also on a G4
(OS 9.2.2), Stage A passes.

## What failure looks like

Window title: **MacTLSTest — smoke FAILED**

Window body:
```
macTLS Stage A smoke: FAILED (code N)
Gate: <human-readable description>

Click mouse or press any key to quit.
```

Failure codes (see [`../os9/ostls_smoketest.h`](../os9/ostls_smoketest.h)):

| Code | Gate                             | Most likely cause |
|------|----------------------------------|-------------------|
| 100  | engine error after reset         | A specific BearSSL constraint fired during init. Inspect `br_ssl_engine_last_error()` value by running under MacsBug or adding an additional probe. |
| 101  | engine not asking to send        | Reset succeeded but engine entered CLOSED immediately. Cipher-suite or hash registration probably dropped a required algorithm. |
| 102  | `br_ssl_client_reset` returned 0 | Almost always `BR_ERR_NO_RANDOM` — entropy didn't reach the engine before reset. Check `OSTLS_InjectStageAEntropy` is being called and `br_ssl_engine_inject_entropy` is linked. |
| 103  | entropy inject failed            | Our stub returned non-zero. Check `Microseconds`, `LMGetMouse` actually compiled in. |

If the app **crashes** (rather than reporting a code), the most likely
classes are:

- **Missing `'carb'` resource** → app fails to load CarbonLib. Confirm
  `MacTLSTest.rsrc` is in the project file list.
- **Stack overflow during `br_ssl_client_init_full`** → bump the
  PPC PEF Application Heap Size to 8 MB and try again.
- **CW8 PPC 64-bit codegen miscompile** in `i31_moddiv.c` →
  separately run the [`../tools/probes/ppc_mul64/`](../tools/probes/ppc_mul64/)
  probe to confirm. If the probe also fails on the same machine /
  optimisation level, that's the root cause and the fix is the PPC
  inline-asm shim documented in the probe README.

## What's next (after smoke OK)

Stage A.5: run the [`mul64 probe`](../tools/probes/ppc_mul64/) on the
same G3 / G4 × 3 optimisation levels.

When both gates close, this app evolves into **MacTLS Proxy**:

- Keep `main.c`'s toolbox init.
- Replace the "show result + wait" tail with: TCP listener on
  `127.0.0.1:8765`, accept loop, HTTP proxy parser, fork a per-request
  pump that performs the upstream TLS fetch via BearSSL through
  Open Transport, and forwards plain HTTP back to the requesting
  browser.
- Same project layout, same prefix, same `.rsrc`.

That work is Stage B / C — explicitly blocked until both Stage A gates
pass on real hardware.
