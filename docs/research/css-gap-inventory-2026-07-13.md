## (a) Parsed-but-dropped — accessor + parser + getter exist, NO layout/redraw consumer

These 19 accessors are declared in `computed.h`, have a parse handler under
`browser/libcss/src/parse/properties/`, and a getter definition in
`browser/libcss/src/select/computed.c`, but are **called by zero layout/redraw code**
under `browser/netsurf/` (the only references, if any, are in `dump.c`, the diagnostic
style-dumper). The bytes are parsed and stored, then silently ignored at layout.

Full list (from `comm -23` of the accessor-decl set vs the used-in-netsurf-excl-dump set):

`box_decoration_break`, `break_after`, `break_before`, `break_inside`, `caption_side`,
`caret_color`, `fill_opacity`, `hanging_punctuation`, `image_rendering`,
`list_style_position`, `macsurf_grid_col_span`, `orphans`, `page_break_after`,
`page_break_before`, `page_break_inside`, `stroke_opacity`, `unicode_bidi`, `widows`,
`writing_mode`.

**Spot-verified anchors (re-grepped this session):**

1. **`caret-color`** — declared `computed.h:337`; parser `parse/properties/p_caret_color.c`
   present; getter defined in `select/computed.c` (1 def). `grep -rn css_computed_caret_color
   browser/netsurf/` → **zero hits** (not even in `dump.c`). Parsed and dropped.
2. **`writing-mode`** — declared `computed.h:552`; parser
   `parse/properties/autogenerated_writing_mode.c`; getter in `computed.c`.
   `grep -rn css_computed_writing_mode browser/netsurf/` → **zero hits**. Parsed and dropped.
3. **`unicode-bidi`** — declared `computed.h:702`; parser exists; getter in `computed.c`.
   Only reference in the whole tree is the diagnostic dumper `dump.c:1696`
   (`val = css_computed_unicode_bidi(style);`). No layout/redraw consumer.
4. **`fill-opacity` / `stroke-opacity`** — declared `computed.h:601` / `computed.h:605`;
   parsers `parse/properties/p_fill_opacity.c` (+ `fill_opacity.c`); getters in `computed.c`.
   Zero consumers under `browser/netsurf/`. (SVG-only paint props; inert without an SVG
   paint pipeline.)
5. **`orphans` / `widows` / `break-*` / `page-break-*`** — e.g. `orphans` declared
   `computed.h:723`, `widows` `computed.h:727`, `break_before` `computed.h:627`,
   `break_after` `computed.h:624`, `break_inside` `computed.h:630`; each has a parser
   (`autogenerated_orphans.c`, `autogenerated_break_before.c`, `ag_page_break_before.c`, …)
   and a getter. Zero layout consumers — correct, because MacSurf has no paginator/multicol
   fragmentation engine (screen-first). These are legitimately dropped until print support.

For contrast, a *live* consumer looks like `css_computed_color` — called at
`redraw.c:1020` (`css_computed_color(box->style, &c);`) and `font.c:162`
(`css_computed_color(css, &col);`). That is what "consumed" means here.

**Impact tiers within (a):**
- *Cosmetically visible if wired:* `caption-side`, `list-style-position`,
  `caret-color`, `image-rendering`. Low effort (single paint/layout branch each).
- *Needs a subsystem, correctly dropped for now:* `writing-mode`, `unicode-bidi`
  (logical-axis + UBA), `break-*`/`page-break-*`/`orphans`/`widows` (paginator),
  `hanging-punctuation` (Unicode-category line-break work).
- *Inert without SVG paint:* `fill-opacity`, `stroke-opacity`.
- *MacSurf-internal:* `macsurf_grid_col_span` (grid vendor prop; its
  span consumption path differs from the standard accessors — verify separately before
  treating as a real gap).

## (b) MISSING_PARSER — no enum entry at all in `properties.h` (never parsed natively)

These have **no `CSS_PROP_*` slot**, so libcss never tokenizes them into computed style.
Confirmed absent this session:
`grep -niE 'background_clip|background_origin|appearance|justify_items|justify_self|grid_auto'
browser/libcss/include/libcss/properties.h` → **no matches**.

- **`background-clip` / `background-origin`** — absent. No enum, no parser, no accessor.
  A real native property add (enum slot + parser + `dispatch.c`/`s_dispatch.c` pair +
  computed storage + accessor + layout/redraw consumer).
- **`appearance`** — absent. (Form-control native look; low payoff on classic Mac.)
- **Intrinsic-sizing keywords `min-content` / `max-content` / `fit-content`** — absent as
  sizing values: `grep -niE 'MIN_CONTENT|MAX_CONTENT|FIT_CONTENT'
  browser/libcss/include/libcss/{computed.h,properties.h}` → **no matches**. `min-width`
  (`properties.h:72`) and `max-width` (`properties.h:70`) exist as properties, but the
  intrinsic-sizing *values* do not. This is the LEAD item — see backlog below.

**Correction vs the source plan (DIRECTIVE #1 — report the code, not the plan):** the
plan listed *grid `justify-items`/`justify-self` and `grid-auto-*`* under MISSING_PARSER.
The code reality this session is that those are **preprocessor-shimmed in `cssh_css.c`**,
not simply absent — they are re-categorized into (c) below. There is still no *native
libcss* property for them, but they are not un-handled at the source level.

## (c) Preprocessor-shimmed in `cssh_css.c` (text-level rewrite before libcss)

`browser/netsurf/content/handlers/css/cssh_css.c` (6443 lines) is a pure text-level CSS
rewriter that runs before libcss sees the stylesheet. It maps modern/absent syntax onto
properties libcss (plus the MacSurf grid vendor props) can parse. All `macsurf__rewrite_*`
functions below are **defined and invoked** (call sites verified this session in the
`macsurf__rewrite_inline_style` / source-rewrite chain around lines 5519–5752):

| Standard input | Rewriter (def line) | Emits / target |
|---|---|---|
| `grid-template-columns` | `macsurf__rewrite_grid_template_columns` (777) | track-list → `-macsurf-grid` |
| `grid-template-rows` | `macsurf__rewrite_grid_template_rows` (880) | → `-macsurf-grid-rows` |
| `grid-column` / grid placement | `macsurf__rewrite_grid_placement` (1428), `_grid_column` (1213) | span → `-macsurf-grid-col-span` |
| `grid-template-areas` / `grid-area` | `macsurf__rewrite_grid_template_areas` (1900) | numeric placement |
| `place-items`/`place-content`/`place-self`/`justify-items`/`justify-self` | `macsurf__rewrite_grid_alignment` (4762, invoked :5536) | split shorthands; `justify-content` is a real libcss prop, `justify-items` also emits a `text-align` shadow |
| `grid-auto-flow` | `macsurf__rewrite_grid_auto_flow` (5061, invoked :5548) | `-macsurf-grid-flow: N` (emit at **cssh_css.c:5202**), consumed via `CSS_PROP_MACSURF_GRID_FLOW` (`properties.h:161`) |
| `text-shadow` | `macsurf__rewrite_text_shadow` (2062) | numeric 4-value form |
| `transform` | `macsurf__rewrite_transform` (2126) | `-macsurf-transform` |
| `object-position` | `macsurf__rewrite_object_position` (2173) | `-macsurf-*` |
| `linear/radial gradients` (image + bg shorthand) | `_background_image_gradient` (2247), `_background_shorthand_gradient` (2376), `_repeating_gradient_hstripe` (2983), `_repeating_gradient_solid` (3633) | gradient plumbing |
| `calc()` aspect | `macsurf__rewrite_calc_aspect` (2831) | aspect-ratio |
| dotgrid pattern | `macsurf__rewrite_dotgrid_pattern` (3197) | `-macsurf-dotgrid` |
| modern compat shims | `macsurf__rewrite_modern_compat` (3733) | misc |
| `inset` shorthand | `macsurf__rewrite_inset` (3976) | top/right/bottom/left |

| `@`-rules normalization | `macsurf__rewrite_at_rules` (4412) | at-rule cleanup |

**Implication:** grid alignment and `grid-auto-flow` "work" only to the extent the
text-level rewriter recognizes the syntax; anything the rewriter doesn't match is dropped
before libcss. A native property port would replace the shim; until then this file is
where grid/transform/gradient/logical coverage actually lives.

## (d) Intentionally-unsupported / niche (deferred by design)

- **Effects:** `transition`, `animation`/`@keyframes`, `clip-path`, `mask`, `filter` —
  need an animation timeline or per-pixel offscreen compositing QuickDraw/classic Mac
  can't do cheaply. Deferred (Group 5 of css-missing-properties.md).
- **`writing-mode` (non-`horizontal-tb`) and full `unicode-bidi`** — need a logical-axis
  layout model + Unicode Bidi Algorithm + glyph rotation. Very low payoff for a Western
  classic-Mac browser; support `horizontal-tb` + `direction` base only.
- **`hyphens: auto`** — needs per-language Liang/TeX dictionaries (RAM/ROM budget). Ship
  `manual` only.
- **Fragmentation** (`break-*`, `page-break-*`, `orphans`, `widows`) — no paginator/
  multicol engine; no-ops on a scrolling screen browser until print support lands.
- **`hanging-punctuation`** — small char set but touches width-accounting + break logic
  for negligible real-world payoff.

## HIGH-impact backlog — sorted by DEPENDENCY ORDER (not flat impact)

> **Read this ordering as a dependency graph, not a priority poll.** The intrinsic-sizing
> solver is a *prerequisite*, not a peer. A future round must NOT pick `background-clip`,
> `table-layout: auto`, or "fix flex/grid collapse" before the sizing solver they depend
> on — doing so builds on sand and will be redone.

**0. min-content / max-content / fit-content intrinsic-sizing solver — LEADS (prerequisite).**
   Absent today (category b: no `MIN_CONTENT`/`MAX_CONTENT`/`FIT_CONTENT` keywords —
   verified this session). This is the foundation the next two items sit on:
   - **`table-layout: auto` DEPENDS on it** — the auto table algorithm distributes column
     widths from per-column min/max content widths; without a min/max-content solver there
     is nothing to distribute.
   - **Correct flex/grid collapse DEPENDS on it** — shrink-to-fit, flex-basis `auto`
     resolution, and grid track `min-content`/`max-content`/`fit-content()` sizing all
     consume the same intrinsic-size computation. (Note: grid tracks are currently
     preprocessor-shimmed in `cssh_css.c` around `minmax()`/`fit-content()` collapse at
     lines ~323/452/695 — a native solver would replace that heuristic.)
   - Also feeds `overflow-wrap: anywhere` vs `break-word` min-content difference.
   *Do this first. Everything below that says "needs #0" is blocked on it.*

**1. `table-layout: fixed`** (independent of #0 — single pass off row 1). Safe to start in
   parallel; also enables reliable in-cell `text-overflow`. **`table-layout: auto` — needs #0.**

**2. `overflow-wrap` / `word-wrap` + `word-break: break-all`** — line-breaker emergency
   breaks. The *breaking* is independent, but the correct **min-content contribution**
   (`anywhere` vs `break-word`) **feeds #0**; wire the breaker first, reconcile min-content
   when #0 lands.

**3. Easy visual wins, independent of #0** (can be done any time): `text-overflow: ellipsis`
   (QuickDraw ClipRect makes it trivial), `tab-size`, `text-align-last`, `empty-cells`
   (paint-time boolean), two-value `gap: A B`, `caption-side` / `list-style-position`
   (both currently parsed-but-dropped, category a — just need a layout branch).

**4. `background-clip` / `background-origin`** — native property add (category b).
   **Independent of #0**, but explicitly do NOT let its "easy paint" framing jump it ahead
   of #0 in a resourcing decision — it delivers less structural value than unblocking
   tables + flex/grid via the sizing solver.

**5. `border-collapse` conflict resolution** — table paint/layout correctness; sequence
   after `table-layout: fixed` (#1) since it shares the table module.

**Dependency summary:** `#0 (sizing solver)` → unblocks `table-layout:auto` and
`flex/grid collapse` and `overflow-wrap min-content`. `#1/#3/#4` are independent and can
be scheduled around #0, but must not *displace* it.
